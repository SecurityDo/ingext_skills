Built from the daily scheduled-report archive. Each day is one stored run for that UTC day, so the page answers any range without searching. It names users and source IP addresses (most active users, failed users, failed IPs, admin actors), so treat it as personal data and share it with care. Each list holds the top 100 values a day, so a range total is a lower bound for anyone who never reached a day's top 100. Days archived before these lists existed are missing from them. Distinct-user figures are not shown, since they cannot be added across days. A day with no archived result shows as a gap, never as zero. Facet rows marked (other) are events not covered by the top values the engine keeps each day. This is evidence of activity volume, not a statement of compliance.
