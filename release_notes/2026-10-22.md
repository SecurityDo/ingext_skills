# 2026-10-22 — executive-report 1.0.0 and compliance-assessment 1.0.0 (new)

## Skills updated

| Skill | Version | Status |
| --- | --- | --- |
| executive-report | 1.0.0 | released |
| compliance-assessment | 1.0.0 | released |

## What changed

- New skill: turns analysis already in hand into a self-contained executive HTML report plus a
  mail-ready PDF (title footer, `X of Y` page count), with an executive-lead structure and a
  print QA gate.
- `scripts/render-html-pdf.mjs` no longer hardcodes a Chrome path or a user-specific Playwright
  location: it searches the usual macOS/Linux/Windows Chrome paths, honours `--chrome` and
  `CHROME_PATH`, and finds Playwright locally or globally.
- Dropped the companion app's inline-widget trigger table; it does not apply here.
- compliance-assessment: per-tenant, per-month compliance evidence report built directly on the
  tenant connector's tools (KQL, behavior summaries, resource dumps via get_resource_dump_url, connector inventory), not on
  the MSSP compliance engine. `scripts/build_report.py` parses the saved raw results, maps them to
  13 NIST 800-53 Rev. 5 control groups, and renders the HTML that executive-report turns into a
  PDF. Missing evidence renders as "not collected" and never as a number. First run: against a test tenant on the
  Develop connector.
