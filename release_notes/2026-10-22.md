# 2026-10-22 — compliance-assessment 1.0.0 (new)

Ported from the Fluency companion app (`fluency-mcp4mssps`), reworked to run on the tenant
connector's own tools instead of the MSSP compliance engine.

## Skills updated

| Skill | Version | Status |
| --- | --- | --- |
| compliance-assessment | 1.0.0 | released |

## What changed

- New skill (in `reports/`): per-tenant, per-month compliance evidence report. It checks
  `list_data_tables` first, queries event tables (Office365, AzureSigninLogs, AzureAuditLogs,
  WindowsAudit) with `kql_search`, and takes resource tables (users, devices, Conditional Access
  policies, Qualys hosts) from resource dumps via `get_resource_dump_url`.
- `scripts/build_report.py` parses the saved raw results, maps them to 13 NIST 800-53 Rev. 5
  control groups and renders a self-contained HTML. Missing evidence renders as "not collected"
  and never as a number.
- `scripts/render-html-pdf.mjs` renders the HTML to a Letter PDF with a title footer and an
  `X of Y` page count. It searches the usual macOS/Linux/Windows Chrome paths, honours `--chrome`
  and `CHROME_PATH`, and finds Playwright locally or globally.
- First run: against a test tenant on the Develop connector.
