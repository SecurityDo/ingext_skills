## What changed

- New resource table: `office365ConditionalAccessPolicy` (56 fields, 5 example queries),
  from `ingext_schema` 08cb43e (`datatypes/Office365Resources/`). It is a snapshot table:
  one row per policy, current state, so queries take no time filter and no dedup step.
  - The schema warns about five traps. MFA can come from `authenticationStrength` while
    `builtInControls` is empty. `grantControls` is null on session-only policies.
    `mv-expand` of an empty array still yields a row. `createdDateTime` is null on older
    policies. Graph adds `@odata.context` keys that mean nothing.
  - The example queries cover: the posture inventory, legacy-auth block coverage, users
    excluded from enabled policies, report-only and disabled policies, and recent changes.
- **SKILL.md:** the table is added to the list of example resource tables.
- No other table changed. `--check` passes against `ingext_schema` (49 tables, `ASSET`
  kept). `cowork/ingext-kql.skill` rebuilt.
