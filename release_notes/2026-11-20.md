# 2026-11-20 — ingext-kql 1.1.7 → 1.1.8

Schema resync from `ingext_schema`: the Oracle Database unified audit table is added.

| Skill | Version | Status |
| --- | --- | --- |

## What changed

- **OracleUnifiedAudit schema** (new, data type `Oracle`): Oracle unified audit trail events
  forwarded by Cribl over HEC (root `@oracleAudit`, fields referenced bare). Covers logons and
  logoffs, account and privilege changes (`object_name` is the account changed), the derived
  `outcome` and `error_code` (`ORA-<n>`), and the traps: `timestamp` is receive time, a session's
  records share one millisecond (order by `entry_id`), `session_id` is unique per database only
  (pin `host`), `database_user` vs `current_user` under definer's-rights PL/SQL. Six example
  queries: action overview, failed logons, account and privilege changes, session trace, logons
  per account, SYS logons per hour.
- `references/schemas/manifest.json` regenerated (52 tables).
- `cowork/ingext-kql.skill` rebuilt.
