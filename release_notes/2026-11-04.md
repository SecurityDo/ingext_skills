# 2026-11-04 — windows-server-activity-report 1.0.1, compliance-assessment (log retention fix)

| Skill | Version | Status |

## windows-server-activity-report 1.0.1

- New `--interactive PATH` option on `build_report.py` writes one self-contained interactive HTML page from the
  same merged archive data: tabs (Overview, Events and hosts, Logons and failures, Privileged and changes,
  Services and tampering, Coverage, Daily counts), search, sort, minimum-count filters, CSV export of the filtered
  view, dark mode and hover trend charts. The trend explorer is a counter dropdown. `--no-actors` omits user names
  and IP addresses from it as well.
- Template added at `assets/interactive_template.html`; SKILL.md Step 3 mentions the option.
- Package `cowork/windows-server-activity-report.skill` rebuilt.

## compliance-assessment (version unchanged, 1.8.1)

- AU-4 / AU-11 (log storage and retention) is always **supported**, with the stated fact that log data is stored for
  one year (365 days) on the Fluency platform. Nothing is searched to measure it: the retention probe (`take 1`
  queries at 90, 180, 270 and 365 days) is removed from the workflow, and any `retention_<Table>_<age>.json` file is
  ignored.
- The "Twelve-month retention not yet evidenced" finding and the retention gap item are gone. History depth
  (`history_` queries) stays as optional information and no longer changes the status.
- Package `cowork/compliance-assessment.skill` rebuilt.

## guardduty-resource-report 1.0.0 (new)

- AWS GuardDuty findings report for one tenant, built only from the archive of the scheduled report
  `GuardDuty_Resource_Report` (no searches, no dumps): print-style HTML, interactive HTML, PDF, `findings.csv`,
  `types.csv`, `resources.csv` and `daily.csv`.
- Findings are counted once by id at their latest update; the 30-day window of stream updates is combined with
  GuardDuty's current list. Attention score: severity High 3, Medium 2, Low 1, plus 1 when updated in the last
  7 days, archived 0; 3 or more needs action.
- Interactive tabs: Overview (with a trend dropdown), Findings, Types and categories, Accounts and regions,
  Resources, Coverage, Daily counts (last).
- Package `cowork/guardduty-resource-report.skill` added.
