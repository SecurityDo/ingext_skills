## What changed

- **One home for the brand kit: the `fluency-report` skill.** `brand.css`, `fluency_brand.py` (page, hero, KPI, band, table, bar,
  callout and footer helpers plus `apply_brand()`), `fluency_mark.png`, the IBM Plex fonts and `render_pdf.mjs` live only in
  `fluency-report/scripts/`. The other report skills no longer carry a copy: their build scripts locate the `fluency-report` skill
  next to them (or at `FLUENCY_BRAND_DIR`) and import `fluency_brand` from it, and stop with a clear message if it is missing.
  Their SKILL.md files list `fluency-report` as a prerequisite and call its `render_pdf.mjs`. Install `fluency-report` with any report skill.
  The per-skill `render-html-pdf.mjs` copies are removed. Template `assets/*.html` files still embed the generated CSS so they stay fill-in-place.
- HTML reports are one self-contained file (logo, fonts and CSS inlined). Build scripts pass their HTML through
  `fb.apply_brand(...)` just before writing it, so existing report logic is unchanged.
- PDFs are rendered from that same HTML by `scripts/render_pdf.mjs` (Playwright and Chromium, US Letter, the page's own
  print CSS, no paged footer; the page carries its own brandline and closing footer line), so the PDF matches the HTML.
  This replaces the WeasyPrint path in o365-activity-report and office-user-investigation and the browser-print and
  `chromium --print-to-pdf` instructions in the resource reports. `render-html-pdf.mjs` is kept as the same renderer.
- The look follows the Fluency Security posture sample: white paper, IBM Plex Sans and Mono, brandline (lock mark + FLUENCY SECURITY)
  over a black rule, large black title, gray lead and mono meta line, KPI strip with status tags, three-column band, blue `§N` section
  markers, flat mono tables, black/gray/blue bars, gray callout and black "Net read", P1/P2/P3 actions and a methodology block.
  Palette is ink, gray, one blue (#175d9a), one red (#b3242e) and one amber (#a06c00); no cards, gradients or rounded boxes.
  `fluency-report`'s `base_template.html`, `widget_recipes.md` and SKILL.md are rewritten around this design (placeholders:
  report_title, cover_eyebrow, report_lead, cover_meta, cover_kpis, report_band, sections, report_actions, report_method, ...).
  Older report scripts keep their markup; `apply_brand()` restyles it and remaps legacy chart colours to the palette.
- Templates rebuilt on the kit with the same placeholders: `security-agent-deployment-status-report`, `azure-user-signin-investigation` and the four resource reports'
  `report_template.html`. `ingext-health-monitor` now builds its page with the kit instead of the old dark theme.
- Interactive HTML pages (the four resource reports, windows-server, the Entra explorer) keep their own layout but now use a
  monochrome palette (grays, light and dark); severity reads by shade, not hue.
- Left unchanged on purpose: `incident-investigation`'s closure renderer (already Fluency-branded, partner-logo override kept), bluevision-report
  (distributor branding), billing and dashboard skills.
- Tools: report skills call only Ingext tools (`kql_search`, `run_report`, `list_report_archive`, `list_resource_dumps`,
  `get_resource_dump_url`, ...). No other application's tools are used.
- Packages in `cowork/` rebuilt for every skill listed above; `guardduty-resource-report` (1.0.0, new) is included.
- The four resource reports (Defender, Falcon, SentinelOne, GuardDuty) have a fixed structure: the script lays out the same KPIs, panels, tables and next steps every run, and the summary and next-steps text are generated from the numbers. `narrative.json` is now optional wording only (SKILL.md step 5), and status colours in the scripts use the editorial palette.
- `fluency-report` gains chart helpers in `fluency_brand.py` (and a recipe section): vertical, grouped and stacked columns, grouped and stacked horizontal bars, heatmap, scatter and line chart, all inline SVG/CSS in the editorial palette.
- Also added `gauge`, `segment_bar` and `sparkline` helpers; donut, gauge and stacked bar use the editorial palette.

## Chart gallery as the source of truth

- Every report chart now comes from the shared `fluency_brand` helpers: per-day columns (hatched gap for missing days), horizontal bars, stacked severity columns, time charts, the risk matrix and the resource-report bars and trends. Hand-written SVG, dark charts and inline bar markup are gone (the geomap and the Azure sign-in timeline stay bespoke, restyled to the palette).
- `fluency-report/assets/chart_gallery.html` and `.pdf` show every chart, table and component with the exact helper call; regenerate with `scripts/chart_gallery.py`.
- The four resource reports now import the brand kit like the other report skills.

## New: ransomware-readiness-report (R02)

- Board ransomware readiness report from the library (R02): overall rating, eight-pillar scorecard, ranked issues, 90-day roadmap, strengths. HTML and PDF in the editorial style; the overall rating is computed from the pillar statuses.
- Evidence queries are in `references/query_playbook.md`, checked against a tenant with SentinelOne, Defender and Windows audit data. Backup product versions are compared with a listed advisory set; unlisted versions are reported as "CVE status not verified".
- Fixes in the shared kit: red callouts no longer split into columns; KPI cells holding a word (for example an overall rating) use smaller type.
