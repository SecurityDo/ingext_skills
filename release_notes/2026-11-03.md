## sentinelone-resource-report 1.0.0 — new

**One report for the three SentinelOne resource types** (`sentinelOneAgent`, `sentinelOneApplication`,
`sentinelOneThreat`), processed locally from resource dumps with no searches and no saved report.

- Agents: reporting state with days silent, agent versions against the newest build in the fleet, operating
  systems, machine types, protection mode, patching and reboot flags.
- Applications: installs and distinct applications, risk levels, top publishers, the medium and high-risk
  applications with the endpoints that carry them.
- Threats: history by classification, confidence and week, top threat names and endpoints, open threats (not
  mitigated, or incident not resolved).
- Applications and threats are joined to agents on the agent UUID. Each endpoint gets a score (needs action,
  watch, healthy) with the reasons listed; full scan age is shown but not scored.
- Output: print-style HTML for the PDF, a self-contained interactive HTML file (tabs, search, sort, filters,
  CSV export of the filtered view, dark mode), and `endpoints.csv`, `applications.csv`, `threats.csv`.
- The interactive file and `endpoints.csv` carry endpoint names and last logged-in users; `--no-actors` leaves
  the user names out.
- Tested on a 58-endpoint tenant (2,462 application installs, 471 threats), including an agents-only tenant and
  an empty agent dump.
- Package `cowork/sentinelone-resource-report.skill` added.

## falcon-resource-report 1.0.0 — new

**One report for CrowdStrike Falcon hosts and detections**: the `falconAgent` resource dump joined to
`FalconAlert` (last 30 days) on `agent_id` = `device_id`.

- Hosts: check-in state, sensor releases, platforms and roles, reduced functionality mode, provisioning,
  prevention policy, containment, uninstall protection, safe mode. Each host gets a score (needs action, watch,
  healthy) with the reasons listed.
- Detections: endpoint (`epp`) detections and automated leads by severity, status and tactic; an open High or
  Critical detection adds 3 to the host score, any other open detection or lead adds 1. Other alert products
  are fleet totals only.
- Output: print-style HTML for the PDF, a self-contained interactive HTML file (Detections tab, search, sort,
  filters, CSV export, dark mode), `hosts.csv`, `alerts.csv`, `policies.csv`.
- Detections are read from the archive of the scheduled report `CrowdStrike_Resource_Report` (`--alerts-archive`); `kql_search` is only the fallback for a tenant without that archive: it runs the same three queries as the report (per host, one `facet` query for severity, status, tactic and detection name, other products) over the same 30-day window.
- Package `cowork/falcon-resource-report.skill` added.
