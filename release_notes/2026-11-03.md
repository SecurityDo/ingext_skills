## sentinelone-resource-report 1.0.0 — new

**One SentinelOne resource report per tenant, built only from the archive** of the scheduled report
`SentinelOne_Resource_Report`. It never runs a search and never reads a resource dump.

- Endpoints: reporting state with days silent, agent versions against the newest build, protection mode, patching.
- Applications: installs, risk levels, the 25 most widespread applications.
- Threats: history by classification, status and week; open threats (not mitigated, or incident not resolved).
- Each endpoint gets a score (needs action, watch, healthy) with the reasons listed.
- Each archived day is a snapshot: the report uses the latest day and shows a change table across days. Missing
  days are reported, with `backfill_report_archive` offered.
- Output: print-style HTML for the PDF, a self-contained interactive HTML file (tabs, search, sort, filters, CSV
  export, dark mode), `endpoints.csv`, `applications_top.csv`, `open_threats.csv`.
- Package `cowork/sentinelone-resource-report.skill` added.

## falcon-resource-report 1.0.0 — new

**One CrowdStrike Falcon resource report per tenant, built only from the archive** of the scheduled report
`CrowdStrike_Resource_Report` (hosts and 30 days of `FalconAlert` detections). It never runs a search and never
reads a resource dump.

- Hosts: check-in state, sensor releases, platforms and roles, prevention and other policy coverage. Each host
  gets a score (needs action, watch, healthy) with the reasons listed; hosts with a score above 0 are listed
  (first 500), healthy hosts are counted.
- Detections: endpoint (`epp`) detections and automated leads by severity, status and tactic; hosts with open
  detections. Other alert products are fleet totals only.
- Output: print-style HTML for the PDF, a self-contained interactive HTML file (Detections tab, search, sort,
  filters, CSV export, dark mode), `hosts.csv`, `alerts.csv`, `policies.csv`.
- Package `cowork/falcon-resource-report.skill` added.

## defender-resource-report 1.0.0 — new

**One Microsoft Defender for Endpoint resource report per tenant, built only from the archive** of the scheduled
report `Defender_Resource_Report`. It never runs a search and never reads a resource dump.

- Devices: enrolment coverage, check-in recency, operating systems, device groups, antivirus health, exposure and risk.
- Vulnerabilities: severity by exploitability, top exploitable CVEs, software with the most critical CVEs.
- Secure configuration compliance by category and the most common failing settings; top security recommendations.
- Alerts and incidents: informational alerts are shown but not scored.
- Each onboarded device gets a score (needs action, watch, healthy) with the reasons listed; the 500
  highest-scoring devices are listed, the rest are counted.
- Output: print-style HTML for the PDF, a self-contained interactive HTML file (tabs, search, sort, filters, CSV
  export, dark mode), `hosts.csv`, `alerts.csv`, `vulnerabilities.csv`, `config.csv`.
- Package `cowork/defender-resource-report.skill` added.
