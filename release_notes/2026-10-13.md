# 2026-10-13 — security-agent-deployment-status-report

A new report skill: a client-ready **security agent deployment status** report for a Fluency /
Ingext account, built from the account's inventory resource dumps and processed locally.

## Skills added

| Skill | Version | Status |
| --- | --- | --- |
| security-agent-deployment-status-report | 1.0.0 | released |

## What it does

- **Download, then process locally.** One `list_resource_dumps` call, then one
  `get_resource_dump_url` call per dump, each fetched straight to disk with `curl` (the links
  expire after 15 minutes). The dump data never passes through the conversation. The bundled
  `scripts/deployment_status.py` (standard library only) does the matching and writes
  `facts.json`, `devices.csv` and a Fluency-branded HTML page that prints to A4.
- **Per-device model.** Devices are matched across inventories by Entra device ID, then by
  normalized hostname. Each required agent is active, stale or missing on each device, and the
  device is Compliant, Missing agent, Agent not reporting, or Inactive. The defaults are
  SentinelOne and Defender for Endpoint (required) and Entra ID (reference only, so it never
  creates a gap).
- **Health check first.** `check` flags an empty dump, a filter that matches nothing, no recent
  activity, an empty host field, or a snapshot older than 48 hours. `render` refuses to run while
  a required source is flagged, so a broken integration isn't reported as missing agents.
- **Config-driven sources.** `sources.json` sets which inventories count and how each is
  filtered. Adding Intune, CrowdStrike or AD is a config change; `references/adding_sources.md`
  covers the fields, the filter syntax and the `fields` command for exploring a new dump.
- **Narrative.** The agent writes the summary and next steps into `narrative.json` from
  `facts.json` and `devices.csv`, using only numbers it computed, in client-facing language.

## Notes

- The skill reproduces the `Security_Deployment_Status` FPL report rule for rule, but needs no

- Example values in `references/methodology.md` were replaced with generic ones before
